# PhishGuard

A machine learning project that checks whether a link is **phishing or safe**.

## About

Phishing links trick people into giving away passwords and personal data. This project trains a model on real data to tell phishing URLs from legitimate ones.

## Dataset

* **PhiUSIIL Phishing URL Dataset** (about 235,000 URLs: legitimate and phishing)
* Kaggle: https://www.kaggle.com/datasets/joebeachcapital/phiusiil-phishing-url
